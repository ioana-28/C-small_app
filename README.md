# C-small_app
This application manages university applications in a clear and organized way. The system is structured around universities, each containing multiple faculties, which in turn offer various specializations. 

The app is console-based, allowing users to submit applications to one or more faculties and specializations from a list that is loaded from an external file. Users can easily view all their submissions, and the application provides detailed statistics showing the number of applications submitted to each faculty and specialization. The app also ensures that users can only apply to existing programs by validating input against the available list. 

Additionally, all data is saved in files so that submissions are preserved between sessions. Future improvements could include features like removing or undoing an application, searching submissions, exporting reports, or adding student profiles to track applications more closely.
